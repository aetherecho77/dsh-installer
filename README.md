# dsh-installer

一条命令，把 DeepSeek Harness 从「刚装好、什么都没有」装到「填个 key 就能用」。

```powershell
.\install-dsh.ps1 -Source "C:\Downloads\setup.exe"
```

大约十分钟。装完会给你一份报告，列出装了什么、哪几个没装上、为什么。

---

## 为什么有这个东西

DSH 官方安装包装完之后是一个空壳：界面只有「Sign in」和「Add API Key」。真正干活要的那一堆插件，得自己一个一个 `dsh plugin add`。

手动装一遍大概是这样：先查插件叫什么、在不在 npm 上、跟当前版本兼不兼容，然后一个个装。慢的几个加起来十几分钟，中间还会有「版本门禁」「网络超时」这类看不懂的报错。

这个脚本把这段重复劳动固化了。它不发明任何东西，只是把「我知道该装哪些、按什么顺序装、报错怎么读」写成代码。

还有一层用处：**验证你的灾备**。重装系统之前跑一遍，就知道「我那些插件是真能装回来的，还是只是我以为能」。

---

## 用之前

1. 从 [DeepSeek Harness 官网](https://deepseek.com) 下载安装包，放到本地。
2. Windows 10/11，PowerShell 5.1 以上。
3. 管理员权限（脚本开头会自己检查）。

**注意**：脚本会在第二步启动一次 GUI 来初始化 profile。所以它必须跑在**有交互桌面的会话**里——在服务会话、无桌面的远程环境、CI 里会失败（这一步没有跳过参数，因为 profile 只能由 Electron 应用创建）。

---

## 参数

| 参数 | 作用 |
| --- | --- |
| `-Source` | 官方安装包路径，**必填** |
| `-OfflineDir` | 你自己的离线插件包目录（.tgz），默认 `.\plugins` |
| `-Profile` | profile 名，默认 `desktop` |
| `-SkipPlugins` | 只装本体，不装插件 |
| `-SkipImageGen` | 不装生图插件（体积大） |
| `-SkipWeChat` | 不装微信通道 |
| `-SkipVoiceInput` | 不装语音输入 |

---

## 这个仓库**不包含**什么

- **官方安装包**（`setup.exe`）。请自己去官网下。分发官方软件本体不属于这个项目该做的事。
- **任何 API key**。脚本装完就停，登录和填 key 是人自己做的——那一步既是账户行为，也是唯一能让人知道自己钱花在哪的一步。
- **私有插件**。脚本里的公共插件清单都在 npm 上；不在 npm 上的包请自己放进 `-OfflineDir`，脚本会逐个装。

---

## 已知限制

- 插件安装的耗时差异很大，实测从 2 秒到 7 分钟都有，取决于包大小和网络。不要以为卡住了。
- `dsh plugin add` 有时会因为**版本门禁**拒绝安装（插件没声明兼容当前 Harness）。脚本会单独标出来并给出 `allow-version` 命令，但**不替人接受风险**——装不装由你自己定。
- 装完只是「能填 key」，不代表「能用」。能不能用还取决于你的 key、网络、以及你装的插件本身。

---

## 它在一个真实机器上验证过什么

在一台 Windows 10 19045 上，从全新虚拟机跑过三轮：

- 装本体：约 50 秒
- 初始化 profile：约 3 秒
- 公共插件 10/11 成功，私有离线包 3/3
- 最终 `bundles` 15 项、`dependencies` 13 项
- 全程约 10 分钟

没验证的部分：不同 Windows 版本、不同杀毒软件、企业网络环境下的行为。
